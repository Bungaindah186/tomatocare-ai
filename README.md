
# 🍅 TomatoCare AI
### Sistem Deteksi Penyakit Daun Tomat Berbasis YOLOv8

## 📖 Tentang Proyek

**TomatoCare AI** merupakan aplikasi berbasis kecerdasan buatan (*Artificial Intelligence*) yang dikembangkan untuk membantu mendeteksi penyakit pada daun tanaman tomat menggunakan teknologi Computer Vision dan model YOLOv8.

Proyek ini memanfaatkan model deteksi objek untuk mengenali gejala penyakit pada daun tomat melalui gambar atau kamera, sehingga dapat membantu proses identifikasi awal penyakit tanaman.

## 🎯 Tujuan Proyek

- Mengembangkan sistem deteksi penyakit daun tomat berbasis Computer Vision.
- Menerapkan model YOLOv8 untuk mendeteksi objek pada citra daun tomat.
- Membuat aplikasi yang dapat membantu proses identifikasi awal penyakit tanaman.

## 🧠 Teknologi yang Digunakan

- **Python** — Bahasa pemrograman utama.
- **YOLOv8** — Model deteksi objek.
- **Computer Vision** — Pengolahan dan analisis citra.
- **HTML, CSS, JavaScript** — Teknologi antarmuka web.
- **OpenCV** — Pengolahan gambar dan kamera (jika digunakan dalam implementasi).

## ⚙️ Fitur dan Komponen

- Deteksi penyakit daun tomat menggunakan model YOLOv8.
- Pengelolaan model deteksi melalui folder `weights`.
- Aplikasi berbasis web menggunakan Python.
- Komponen pendukung deteksi dan pengolahan data penyakit.
- Dukungan modul kamera melalui `CameraRT.py` (sesuai implementasi aplikasi).
